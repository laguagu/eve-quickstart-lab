# Tietomalli

`data/myynti-2026.csv`

| sarake          | merkitys                                  |
| --------------- | ----------------------------------------- |
| kuukausi        | ISO-kuukausi, esim. `2026-03`             |
| tuote           | tuotenimi                                 |
| kpl             | myydyt kappaleet                          |
| yksikkohinta_eur| veroton yksikköhinta euroina              |

Liikevaihto = `kpl * yksikkohinta_eur`. ALV ei sisälly hintoihin.
